## 1. Premium Feel vs. Design Direction & Gold Discipline Audit

### Does it read as "Candi Obsidian & Lontar Studio" or generic dark dev-tool slop?
It reads as **a generic dark dev-tool scaffold wearing a warm brown-black & gold stylesheet**—nowhere close to the *premium-playful agency-grade* bar (`tehtariknation.com`, `sweet-tape.com`, `bikebear.com.my`).

- **The "Candi & Lontar" brand concept dies after line 296.** The entire cultural/studio identity consists of a single `20×20` geometric diamond SVG (`brand-mark`, [ui.html](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L295)) and one `20px` serif `<h1>Airlangga</h1>`. Inside `<main>`, `--font-display` is never used again—every card title, section heading, node, modal, and empty state falls back to default OS sans-serif (`Segoe UI` / `Roboto` / `-apple-system`). There are no Lontar/ivory contrast moments, no playful craft, no bespoke icons (even the 5 utility SVGs specified in [uiux-gemini-design.md](file:///home/hatch/workspace/airlangga/uiux-gemini-design.md#L124-L131) were dropped in favor of raw text `×`, `−`, `+`), and virtually zero motion choreography (one `@keyframes pulse` on a `6px` dot at [ui.html](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L109-L110)).
- **Part of the problem starts in the spec itself:** [uiux-gemini-design.md](file:///home/hatch/workspace/airlangga/uiux-gemini-design.md#L109-L122) prescribed utilitarian restraint ("zero blur", "zero shadows on static panels", uniform `4px` radius, pure system fonts, strict tabular CRUD), which pulls toward *austere enterprise console*, not playful Malaysian/SE-Asian agency craft. Then [ui.html](file:///home/hatch/workspace/airlangga/airlangga/ui.html) cut corners *below* even that austere spec.

## 2. Palette, Typography & Spacing

- **Warm obsidian base works; token hygiene is broken.** The `#0D0C0A` / `#161411` / `#1F1C17` warm stone ladder genuinely avoids cold Tailwind slate—that is the strongest visual choice here. However:
  - **`--ochre` is completely UNDEFINED in `:root`** ([ui.html](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L11-L21)), yet referenced in `.pill.ochre` ([L114](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L114)), `.node .badge.ochre` ([L135](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L135)), `#status.warn` ([L198](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L198)), and `#approvalOffWarn` ([L464](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L464)). All four silently lose their ochre text/border color and fall back to inherited text color (`#F4EFE6` or `#B3AA9B`).
  - **Dead vs. hardcoded tokens:** `--btn-sec`, `--danger-border`, and `--nav-bg` are declared at [L14](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L14) and **never referenced**, while `#242019`, `#6E2D28`, and `#12100D` are hardcoded at [L43](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L43), [L81](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L81), and [L92](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L92).
- **Measured contrast failures (WCAG 2.1):**
  - `--border-ctrl` (`#524B3E`) on `--surface` (`#161411`) is **`2.13:1`**—**fails WCAG 2.1 SC 1.4.11 (`>= 3:1` non-text UI contrast)** despite [uiux-gemini-design.md](file:///home/hatch/workspace/airlangga/uiux-gemini-design.md#L74) claiming `>= 3:1`. Resting inputs, selects, buttons, and node borders fade into cards `[needs a real browser]`.
  - `--subtle` (`#8C8375`) on `--surface-3` (`#29251E`) is **`4.08:1`** (fails WCAG AA `4.5:1`).
  - Canvas dot grid `#2A251D` on `#090807` is **`1.32:1`** and card divider `--border` `#2E2A22` on `--bg` `#0D0C0A` is **`1.37:1`**—borderline invisible on non-OLED monitors `[needs a real browser]`.
- **Inverted & flat typographic hierarchy:**
  - `body` is `14px` ([L23](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L23)), **`input, select, textarea` is `15px`** ([L68](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L68)), and **`h2` is `16px`** ([L26](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L26)). Input text is larger than body copy and within `1px` of section headings—collapsing page scanning hierarchy `[needs a real browser]`.
  - `--font-display` is trapped on `h1` alone (`20px` in header, [L25](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L25)), giving zero editorial authority to workspace tabs.
- **Unconstrained full-bleed spacing on wide screens:** `<main>` ([L51](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L51)) has **no `max-width`**. On a `1440px–1920px` desktop, forms and tables in Teams, Models, Files, Runs, and Settings stretch across the entire screen into thin horizontal strips with cavernous empty whitespace between table columns `[needs a real browser]`.
- **Ad-hoc inline spacing:** Over 40 inline `style="..."` margin/padding overrides (`margin:8px 0 0`, `margin-top:10px`, `padding:18px`, etc.) fight `.card` (`padding: 14px`) and `label` (`margin: 10px 0 4px` overridden selectively by `.row > div > label` at [L57](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L57)).

## 3. Navigation & Information Architecture

- **Catastrophic Desktop CSS Leak (`#tab-settings`, [ui.html](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L52), [L241–L244](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L241-L244)):**
  ```css
  .tab { display:none; } .tab.active { display:block; }          /* specificity 0,1,0 / 0,2,0 */
  @media (min-width: 1024px) {
    #tab-settings { display:grid; ... }                          /* specificity 1,0,0 — NO .active! */
  }
  ```
  Because `#tab-settings` (ID selector) overrides `.tab { display: none; }` at `>= 1024px` **without `.active`**, all 5 Settings cards (Telegram, Change UI Password, Approvals & Budgets, Scheduled Jobs, Skills) are **permanently rendered below Graph, Teams, Models, Files, and Runs on every desktop viewport**!
- **Where a first-time user looks first—and why it fails:** After login, the user lands on `Graph` facing a clipped `1496px`-wide wiring diagram (see §4), two competing gold buttons in the toolbar, an empty `300px` right inspector (`"Select a node to edit it."`), and a dev-telemetry badge (`TOKEN ACTIVE`) in the top right. Nothing guides the first-time mental model (*Configure Models → Build Team → Attach Charter → Run*). Even the `#graphEmptyCard` onboarding card ([L340](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L340)) is dead because [L782](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L782) checks `graph().nodes.length ? "none" : "block"`—which is always truthy because `main_brain` exists.
- **Confusing 3-way ownership split & redundancies:**
  - **Member editing exists in 3 places with 3 different UIs:** Graph `#sidePanel` ([L1402–L1416](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L1402-L1416)) uses comma-separated text for Capabilities and hides Fallbacks/Skills; Teams & Models open `#memberModal` ([L1576–L1616](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L1576-L1616)) which uses checkboxes for Capabilities, text for Skills, and a broken member-checkbox list for Fallbacks.
  - **Main Brain splits across Graph and Models:** `Max tokens per call` and `Budget` only exist on Models ([L1735–L1736](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L1735-L1736)), not in Graph `#sidePanel` ([L1393–L1398](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L1393-L1398)).
  - **Inverted Models hierarchy:** `Custom providers` (actionable user config, stored in Settings) is buried at the bottom of Models *underneath* a collapsed `Provider reference` table ([L378–L379](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L378-L379)).
  - **Split authoring:** Charter Markdown files live in `Files`, while Skill YAML playbooks live buried in card #5 of `Settings` ([L479](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L479))—yet the Graph inspector wrongly claims `"Skill file (under files/)"` ([L1433](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L1433)).
  - **Duplicate Sign Out:** Appears in both `<header>` (`#btnSignOut`, [L300](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L300)) and `Settings → Change UI password` (`#btnSignOut2`, [L455](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L455)).
  - **Empty nav counters:** `#countTeams`, `#countFiles`, `#countRuns` ([L304–L307](file:///home/hatch/workspace/airlangga/airlangga/ui.html#L304-L307)) are rendered in HTML and never populated by JS.

## Verdict

**No.** Today, the Airlangga web UI does not clear the premium-playful agency-grade bar—not even close. Beneath a promising warm obsidian/gold color palette, it ships with a desktop CSS specificity bug that leaks the entire Settings page beneath every tab, an undefined `--ochre` token, five completely dead buttons, an inverted heading-vs-input type scale, broken gold discipline on Graph, a live canvas where nodes stack pixel-for-pixel on top of each other and half the edges cut through model cards, a Fallback modal that hides real fallbacks and lies about `WILL SKIP`, and a `390px` phone experience where the graph shrinks to `3.2px` text and edges cannot open the bottom sheet. **The single change that would move it most** is a disciplined visual-and-structural pass on the **Graph canvas + visual hierarchy**—fixing the `#tab-settings` desktop leak and node/edge auto-layout collisions while bringing real `--font-display` editorial typography, iconography, tactile Lontar contrast accents, and strict single-gold-CTA discipline across the workspace—because right now the very first screen an operator sees after login immediately signals "unfinished internal debug tool" instead of a crafted studio.
